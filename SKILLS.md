# ZARVIS Skills

Skills are reusable capability modules selected by the shared Brain.

## Skill contract

A skill should define:

- purpose
- supported inputs
- required capabilities
- required integrations
- risk class
- confirmation requirements
- execution tools
- verification method
- failure/fallback behavior
- platform support

## Planned skill domains

Research, Study, Documents, Writing, Creative, Life Organizer, Automation, Phone/Device, Notifications, Business, Finance, Shopping, Travel, Translation, Email, Meetings, Developer, Multi-Agent, Dashboard, Privacy/Security, Family, Integrations and Smart Home.

## Platform rule

A skill must not claim a platform capability that is unavailable. Platform-specific implementations should remain behind adapters and the shared Brain should expose truthful capability status.
